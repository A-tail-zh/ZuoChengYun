# ZuoChengYun - 算法学习代码库

左程云算法课程学习笔记与代码实现

## 目录结构

```
src/
├── class019/     # 输入输出基础
├── class027/     # 链表与堆
├── class030/     # 哈希表与设计题
├── class036/     # 二叉树遍历
├── class037/     # 二叉树递归
└── util/         # 公共工具类
```

## 命名规范

参考 [algorithm-journey](https://github.com/algorithmzuo/algorithm-journey) 仓库格式：

- 目录：`class{编号}`
- 文件：`Code{序号}_{题目名称}.java`

## 分类说明

| 前缀 | 说明 |
|------|------|
| E (Essential) | 必备 - 基础必掌握题目 |
| X (Extended) | 扩展 - 进阶扩展题目 |
| H (Hard) | 挺难 - 困难挑战题目 |

## 题目列表

### class019 - 输入输出基础
- Code01_ReadInput - 文件输入输出处理

### class027 - 链表与堆
- Code01_MergeKSortedLists - 合并K个有序链表
- Code02_MaxOverlapLines - 线段最大重叠数
- Code03_HalveArray - 将数组减半的最少操作数

### class030 - 哈希表与设计题
- Code01_SetAllHashMap - 设计有setAll功能的哈希表
- Code02_LRUCache - LRU缓存
- Code03_RandomizedSet - O(1)时间插入删除获取随机元素
- Code04_RandomizedCollection - O(1)时间插入删除获取随机元素(允许重复)
- Code05_MedianFinder - 数据流的中位数
- Code06_FreqStack - 最大频率栈
- Code07_AllOne - 全O(1)的数据结构

### class036 - 二叉树遍历
- Code01_BuildTreeFromPreorderInorder - 从前序与中序遍历序列构造二叉树
- Code02_CheckCompletenessOfBinaryTree - 二叉树的完全性检验
- Code03_CountCompleteTreeNodes - 完全二叉树的节点个数
- Code04_BinaryTreeLevelOrderTraversal - 二叉树的层序遍历
- Code05_BinaryTreeZigzagLevelOrderTraversal - 二叉树的锯齿形层序遍历

- Code07_CalculateDepth - 计算二叉树的深度
- Code08_NAryTreeLevelOrderTraversal - N叉树的层序遍历
- Code09_MinimumDepthOfBinaryTree - 二叉树的最小深度
- Code10_SerializeDeserializeBinaryTree - 二叉树的序列化与反序列化

### class037 - 二叉树递归
- Code01_LowestCommonAncestor - 二叉树的最近公共祖先
- Code02_LowestCommonAncestorBST - 二叉搜索树的最近公共祖先
- Code03_PathSumII - 路径总和 II
- Code04_BalancedBinaryTree - 平衡二叉树
- Code05_ValidateBinarySearchTree - 验证二叉搜索树
